# Eveonn Roadmap

## Near term

- Attach `eveonn.xyz` as the production domain.
- Publish the project under the HeySalad GitHub organization.
- Add screenshots and a deploy button to the README.
- Replace placeholder production auth with a real gated demo.
- Add a small public status panel for `/eve/v1/health`.

## Agent features

- Web chat with signed-in access.
- Saved conversation history.
- Agent profile editor for name, tone, model, and instructions.
- Tool catalog showing which TypeScript tools are available.
- Skill library for reusable agent playbooks.
- Scheduled jobs for daily briefings and periodic tasks.
- Human approval gates for actions that mutate external systems.

## Developer experience

- `create-eveonn-agent` starter command or template repo.
- One-click Vercel deploy flow.
- Example tools for GitHub issues, support replies, docs search, and web research.
- Example channels for Slack, Discord, and email.
- Evals for persona consistency and tool behavior.
- Contributor guide and issue templates.

## Platform ideas

- Hosted gallery of community Eve agents.
- Agent uptime and run history dashboard.
- Marketplace-style directory of Eve tools and skills.
- Bring-your-own-model routing through AI Gateway.
- Organization templates for teams building internal agents.
